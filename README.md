# Catalysts Build

Static website made with HTML, CSS, and JavaScript. It has no package installation or build step.

## Files to publish

Publish the project root with `index.html`, `About.html`, `style.css`, `page-transition.js`, and all referenced image files together. Keep the file names and relative paths unchanged.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the files from this folder.
2. Open the repository's **Settings** and select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then save.
5. Wait for the Pages URL to appear in the Pages settings.

## Publish with Netlify

Deploy the project root as a static site using Netlify Drop, or connect the repository. Leave the build command empty and use the repository root as the publish directory.

## Before publishing

The newsletter form is currently visual only and does not store or send email addresses. Connect it to a mailing-list service before collecting subscriptions. Replace placeholder social links with the studio's real URLs when available.
